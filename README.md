# Apple Vision Pro Landing

A luxury scroll-driven landing page for Apple Vision Pro.

## Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- GSAP + ScrollTrigger
- Lenis smooth scroll

## Setup
```
npm install
npm run dev
```

Open http://localhost:3000

## Project status
Complete. Four sections with cinematic scroll storytelling:
- [x] Hero: 150-frame scroll-scrubbed canvas animation
- [x] Statement: Word-by-word text reveal
- [x] Features: Three full-bleed cinematic features with overlay text
- [x] Close: Price, CTA, editorial image
